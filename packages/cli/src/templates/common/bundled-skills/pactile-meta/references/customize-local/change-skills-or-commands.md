# Change Skills or commands

For project-specific guidance, add or edit a user-owned Skill under `.agents/skills/<name>/SKILL.md` or a relevant file in `.pactile/spec/`. Inspect names and ownership before writing.

For lifecycle behavior, change the task contract or CLI command in the Pactile product source, then verify through the public CLI. A generated Skill is an entry point, not a second state store.

Legacy host command and Skill directories are preserved for migration review only.
