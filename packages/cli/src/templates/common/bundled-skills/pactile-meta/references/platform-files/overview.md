# Codex project files

Pactile stores canonical workflow, tasks, and runtime state in `.pactile/`. The active adapter projects managed instructions into `AGENTS.md` and shared Skills into `.agents/skills/`. Optional native Codex configuration is projected only when the host reports support and a reviewed plan supplies its binding.

Inspect the project's ownership ledger before changing a generated file. Existing user content is not a template to overwrite. Older `.cursor/` files are legacy installation data; new Pactile runs do not create or refresh them.
