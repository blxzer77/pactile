# Local customization

Start by reading the project's `.pactile/workflow.md`, `.pactile/spec/`, managed `AGENTS.md` block, and `.agents/skills/`. Determine whether the target is framework-owned or user-owned from the ownership ledger.

| Need | Change |
| --- | --- |
| Project coding convention | `.pactile/spec/` |
| Local Skill | User-owned `.agents/skills/<name>/SKILL.md` |
| Task decision or evidence | The task's PRD, implementation, or verification artifact |
| Pactile product behavior | Product repository and tests |

Do not edit a legacy host directory to add new Pactile behavior.
