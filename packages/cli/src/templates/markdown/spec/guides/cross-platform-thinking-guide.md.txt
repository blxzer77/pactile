# Cross-platform thinking guide

Review Windows, macOS, and Linux behavior before changing a CLI, script, hook, or path contract.

## Check the boundary

- Normalize relative paths to POSIX form for persisted manifests and compare physical filesystem paths using the host's path API.
- Keep shell commands explicit about which shell executes them. Do not assume Bash syntax works in PowerShell or the reverse.
- Treat case folding, symlinks, junctions, drive roots, and line endings as input facts. Reject ambiguous ownership or traversal.
- Use atomic writes for managed files, and preserve user-owned files when a migration cannot prove ownership.
- Confirm executable lookup and child-process errors on each supported OS.

## Verify

Run focused tests for the changed path contract, then check a fresh `pactile init --codex` and an update preview in disposable projects. Inspect generated files and the npm package contents; source-only success is insufficient.

The current v0.5 runtime still includes Python scripts. Node-only runtime migration is a separate v0.6.0 work item and must be verified before claiming Python has been removed.
