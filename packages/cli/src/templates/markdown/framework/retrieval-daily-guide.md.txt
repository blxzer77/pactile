# Retrieval and evidence

Use `rg` for known text and symbols, then read the relevant source. Use a structural or semantic provider only when the task calls for it and the provider readiness probe succeeds. Record file paths, source versions, and observed results in the task's research or verification artifacts.

For current external facts, run Smart Search when configured. If it is unavailable, record the fallback source and its limitations. A search result is a lead until the underlying file, page, or test confirms it.

A retrieval plan describes the next search and its expected evidence. A retrieval pack scores already collected evidence; it does not perform a search. Never turn a provider's presence into a verified claim without a fresh probe and observable result.

Cursor-specific routing, hooks, and semantic counters from older installations are historical compatibility data. They are not part of the active Codex projection.
