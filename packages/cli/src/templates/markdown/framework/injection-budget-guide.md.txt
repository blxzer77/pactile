# Context budget

Keep the per-session context small and evidence-focused. Put durable project constraints in the managed `AGENTS.md` block or user-owned `.pactile/spec/`. Put long task detail in task artifacts and load it when needed.

The default budget is a short orientation, the selected task's acceptance criteria, and only the relevant spec or research files. Before adding a new always-visible instruction, check whether it applies to every task; otherwise keep it on demand.

A generated file or hook registration does not prove that the Codex host delivered content to the model. Verify an observed session result before relying on an injection channel.
