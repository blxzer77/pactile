# Framework Docs (`.pactile/framework/`)

> **Ownership**: These files are **framework-managed**. `pactile update` refreshes them (with the same hash-conflict prompt as `workflow.md`). If you edit one, update will ask before overwriting — prefer putting project-specific norms in `.pactile/spec/` instead, which update never touches.
