# Middleware Protocol v1

> 一种中间件。官方与用户同一契约，只靠 `source` 区分。字段名英文；正文跟 `artifact_locale`（当前 zh）。
>
> Overlay（已拍）：项目 **`.pactile/middleware/`**。默认可进 git。`pactile init` / `pactile update` **永不写入、不删除、不纳入 `.template-hashes.json`**。历史残渣清理走独立 allow-list，不得误删本目录。

Capability router 只声明 `exact` / `semantic` / `structural` / `external`，不绑 Agent 工具名。Manifest 的 `capability` 可以更细（例如 `browser-session`）；路由仍只按四意图，不绑工具名。

## 双轨

| 轨 | PACTILE 管什么 |
| --- | --- |
| 集成 | 本协议：Manifest + Profile + 健康。下表 **shipped** 各路属于此轨（含 MCP 传输）。 |
| Extra | **未**出现在 shipped 表、也 **未**放入 overlay 的宿主 MCP / Agent 配置 → PACTILE 不管、不进健康表 |

`pactile init` **不**写入 `.cursor/mcp.json`，也 **不**强制安装 Playwright / GitHub / codegraph / fast-context。默认 Profile 只把 **smart-search** 标为 required；其余 shipped 为 optional，有探测、缺了不挡无关任务。

## 义务

1. **一种 ABI。** `source: shipped | user` 不是两套协议。
2. **Update 不顶掉。** 用户 overlay 不进模板 hash / 官方 refresh 写集。同 id：用户赢，并报告。
3. **Secret。** Manifest 只许引用（环境变量名 / 平台 Secret），不许写密钥原文。日志与 Artifact 同样禁止。
4. **权限。** 新权限首次启用走一次 Resolution Approval。后续 `update` 不得扩大已批权限；要扩大再批一次。
5. **校验。** 缺必填字段则拒绝接入并说明，不得半接入。
6. **Hook。** 只订 Event Bridge 已有事件。未订阅模块不得让 hook 失败。
7. **协议版本。** Manifest 可带 `protocol: 1`。不兼容升级必须在应用前被发现。

本条不实现安装器、不做商店、不改全局 MCP。可选日后加 `pactile middleware add`，非发布阻塞。

## 生命周期

添加（放入 overlay 的 Manifest）→ 启用/停用（Profile `required` / `optional` / `unset`）→ 移除（用户删 overlay，PACTILE 忘记）。

停用 ≠ 删除文件。官方 shipped 可被用户停用，不得被 `update` 强行再打开。`update` 可刷新 shipped 声明，但不得删用户 overlay，也不得在用户停用后自动重装实现。

同一 capability 多个 Provider：Profile 选一个 active；其余 standby。不得静默抢当前 active。

## 传输类

`transport` 取其一：`skill+cli` | `mcp` | `skill` | `hook`。未登记且未写入 overlay 的宿主配置，PACTILE 不管。

## 发现与健康

发现方式：在 `.pactile/middleware/` 放 Manifest。缺必填字段则拒绝接入。shipped 声明由产品登记；用户 overlay 同 id 时用户赢。

Status / Continue 在任务需要该 capability 时展示 `ready` / `missing` / `failed` / `degraded`。未登记且未 overlay 的 Extra MCP 不进健康表。

## 第一波 shipped（不挡用户自添）

默认 Profile：仅 **smart-search** = `required`。其余 = `optional`（探测缺失则 missing/degraded，不挡不需要该能力的任务）。**pactile-byok** 仍只占位，本批无实现。

| Provider | Profile | capability | transport | 说明 |
| --- | --- | --- | --- | --- |
| smart-search | required `external-knowledge` | external-knowledge | skill+cli | 独立包；缺失则 degrade |
| codegraph | optional | structural | mcp | 默认不装；不进 always-on |
| fast-context | optional | semantic | mcp | 默认不装；Native `@codebase` 不是这一路 |
| playwright | optional | browser-automation | mcp | `@playwright/mcp`；可复现自动化 |
| github | optional | vcs-host | mcp | 官方 GitHub MCP；密钥只引用 |
| cursor-ide-browser | optional | ide-browser | mcp | Cursor **宿主**注入；无独立 npm。非 Cursor 会话 = missing。不得用平台 WebSearch 冒充 |
| pactile-byok | optional 占位 | — | — | **实现与发版延后**；不带 BYOK 安装 |

## Manifest 样例

### smart-search

```yaml
id: smart-search
protocol: 1
capability: external-knowledge
source: shipped
ownership:
  kind: external-package
  name: smart-search
transport: skill+cli
profile: required
readiness:
  probe: cli
  command_hint: smart-search doctor
on_missing: degrade
permissions:
  network: true
  shell: true
  secrets: true
secret_refs: []
update_policy: preserve-user-overlay
```
