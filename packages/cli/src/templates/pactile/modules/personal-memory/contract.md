# `personal-memory`

P29 表名：`personal-memory`（不得改名）。层：on-demand。

## 职责

按明确授权保存和检索稳定偏好、决策及连续性。当前 Task 的状态、批准、失败与候选证据优先保留在 Task；个人记忆不能成为另一份运行时 SSOT。

## 触发/披露

当前任务材料不足、需要已有长期约定时进行窄范围查询。确有长期价值且获用户授权的内容才持久化；可复用适用的原授权，不能把“以后可能有用”当默认同意。

现有 journal 入口为 `pactile session add` / `pactile session search`，参数以 `--help` 为准。内容记录来源、日期和适用范围；易变事实先实查或标注时效。该 journal 是本地记录，不会自动改写宿主的全局记忆配置。

当前产品没有自动 Close→Notes 投影；不承诺自动记笔记、全文 journal 注入或强制记忆回合。需要跨会话交接使用 `session-transfer`，项目通用知识使用 `spec-learning`。

## 停止条件

- 未确认适用授权时不写用户长期偏好、记忆或全局文件。
- 凭据、原始敏感 payload、无关个人内容和猜测不得存入。
- 记忆与当前源码/Kernel/用户指令冲突时核对当前来源，不能反向覆盖它们。
- 查询应围绕当前事实缺口，不遍历全部历史充当每次会话上下文。

## 关掉必须消失

个人记忆存取和连续性步骤不再披露；Task 与项目文档仍可支持完整生命周期，Kernel Close 不增加记忆 gate。

## 不得带走

Kernel/Task 证据；上下文编译；检索打分；项目规范；宿主全局配置；日志存储和物理清理。
